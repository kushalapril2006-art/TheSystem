THE SYSTEM
Windows desktop edition

1. Clone or download this repository into D:\Project\The System.
2. Open The System.cmd in that folder.

The launcher opens a dedicated Microsoft Edge app window. All game code and
fonts are included, so the game works offline. No ChatGPT account is required.
If Edge is unavailable, open app\index.html in a modern browser.

Keep the files in the same location to continue your save. The desktop launcher
uses a local profile at %LOCALAPPDATA%\The System\Profile.

DAILY QUEST: Log push-ups, sit-ups, squats, and distance.
Start with a scaled preset or choose the Episode 3 targets.
Finish all four objectives to claim Full Recovery, three stat points,
and a Random Box. Take a rest day whenever you need to.

STATUS: Allocate stat points and open Random Boxes.
DUNGEON: Use a key to enter the subway instance and fight Kasaka.

For updates, pull the latest app files into the same folder. Earned XP from the original build carries over.

TYPEFACES
The app looks for an installed Heavycrest font by family name. When it isn't
available, it uses the included Journal Fraktur. Body text uses Latin Modern
Roman. For font notices, see app\fonts.
